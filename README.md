# 🚕 Python DA Assignment 2 – Data Visualization

## 📌 Project Overview

This assignment focuses on cleaning, analyzing, and visualizing taxi trip data
using Pandas, Matplotlib, and Seaborn. The dataset contains trip records
including fare, distance, payment method, and borough information. The goal
is to extract meaningful insights through various visualization techniques.

---

## 🎯 Assignment Objectives

- Load and clean the Taxis dataset using Seaborn
- Handle missing values using appropriate strategies
- Create basic visualizations using Matplotlib
- Create advanced visualizations using Seaborn
- Extract meaningful insights from the data

## 📝 Tasks Completed

### 🔧 Data Loading & Cleaning

#### Task 1 – Load Dataset & Check Missing Values
- Loaded Taxis dataset using Seaborn
- Checked for missing values in all columns
- Identified columns with missing data

#### Task 2 – Handle Missing Values
- Filled categorical columns with mode
- Verified all missing values are handled
- Dataset ready for analysis

---

### 📊 Matplotlib Visualizations

#### Task 3 – Line Chart
- Plotted fare over time using pickup timestamp
- Converted pickup column to datetime format
- Visualized fare trends over time

#### Task 4 – Bar Chart
- Grouped data by pickup_borough
- Calculated total fare for each borough
- Visualized total fare comparison across boroughs

#### Task 5 – Pie Chart
- Visualized trip distribution by payment method
- Credit card vs cash vs other payment methods
- Showed percentage distribution of each method

#### Task 6 – Histogram
- Visualized distribution of trip distances
- Used 30 bins for better granularity
- Identified most common distance ranges

#### Task 7 – Box Plot
- Visualized tip distribution for each borough
- Identified outliers and spread of tip amounts
- Compared tip behavior across boroughs

---

### 📈 Seaborn Visualizations

#### Task 8 – Count Plot
- Visualized number of trips per borough
- Manhattan had the highest trip count
- Clear comparison across all boroughs

#### Task 9 – Scatter Plot
- Plotted distance vs fare relationship
- Colored by pickup borough
- Showed positive correlation between distance and fare

#### Task 10 – Heatmap
- Visualized correlation between numerical variables
- Distance and total showed highest correlation
- Fare and total also highly correlated

#### Task 11 – Pair Plot
- Visualized pairwise relationships
- Colored by pickup zone
- Showed relationships between distance, fare, tip, total

#### Task 12 – Violin Plot
- Visualized fare distribution by payment method
- Credit card trips showed wider fare range
- Cash trips had more concentrated fare distribution
